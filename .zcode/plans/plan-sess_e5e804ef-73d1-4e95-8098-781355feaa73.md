# 上下文
实现“@ 私聊/悄悄话”功能：在输入框输入 `@` 弹出候选（伙伴置顶 + 5 名在线真人，含角色小字），支持键入过滤；选中后下一次发送为仅双方可见的云端私聊消息（淡桔红背景 + 桔红左框，新建 `.is-whisper`）；同时聊天头像弹窗与右下在线列表点击均可快捷插入 `@昵称`。当前私聊仅支持伙伴（本地 IndexedDB `companion_messages`），无真人间云端私聊；`chat_messages` 表无 `whisper_to` 字段，RLS 为“已登录可读全部”。

# 关键发现（复用路径）
- **Composer** `src/components/Composer.tsx:84-97,99,259-274,435-456`：现仅监听 `lastIndexOf('@')`，`mentionCandidates=[companion]`，抑制逻辑检查 `after === @name`；插入为 `draft.slice(0,lastAt)+@name+空格`；键盘 `Arrow/Enter/Escape` 已接 IME 防护 `useImeEnter()`；弹窗 `.mention-popover/.mention-item` 在 `src/index.css:2686-2719`，基类 `.popover`。

# 方案概览
新增 `whisper_to uuid + whisper_to_name text` 列到 `chat_messages`（可空），收紧 RLS 为“公开消息或我参与的悄悄话可见”，`insert` 仍 `with check(auth.uid()=user_id)` 允许作者自指。`chatRemote.send/fetch` 透传两字段；`ChatMessage/ChatEntry` 增 `whisperTo?/whisperToName?/isWhisper?`；新增 `.is-whisper` 桔红样式；Composer 重构为“伙伴常驻首位 + 最多5在线真人（过滤）”，选中回调携带 `PresenceMember` 精确 `userId`；App 新增 `pendingWhisper:PresenceMember|null` 单次生效，`handleSend` 分支为 `whisper > companion-private > public`；头像卡与在线列表均改为“点击插入 @并聚焦”。

# 实施步骤

## 1. 数据库与类型（schema + lib）
- `supabase/schema.sql`：`alter table chat_messages add column if not exists whisper_to uuid references auth.users(id) on delete cascade; add column if not exists whisper_to_name text;` 建索引 `chat_messages_whisper_to`，`alter publication ...` 已含表无需改。重写 RLS：
  ```sql
  drop policy "chat is readable by signed-in players" on chat_messages;
  create policy "chat is readable by signed-in players" on chat_messages for select
    using (auth.uid() is not null and (whisper_to is null or whisper_to=auth.uid() or user_id=auth.uid()));
  ```
  同步更新仓库内 RLS 注释。
- `src/lib/chatTypes.ts`：`ChatMessage` 增 `whisperTo?: string|null; whisperToName?: string|null;`；`ChatEntry` 增 `isWhisper?: boolean`（或由 `whisperTo` 推导）。
- `src/lib/chatRemote.ts`：`RoomHandle.send` 参数增 `whisperTo?:{userId:string, displayName:string}|null`；`insert` payload 增 `whisper_to/whisper_to_name`；`fetchChatPage`/`onMessage` 解包回 `whisperTo`；失败重试分支去除新增列时保持兼容。
- `src/lib/chatSync.ts`：`ChatApi.send` 签名同步，透传至 `chatRemote.send`；`ChatEntry` 构造时映射 `whisper_to` 并标记 `isWhisper`；`loadOlder/syncFromServer` 无需额外分支（RLS 已过滤）。

## 2. Composer 重构（@弹窗）
- `src/components/Composer.tsx` Props 增 `presence:PresenceMember[]; selfId:string|null; onWhisperSelect?:(m:PresenceMember)=>void;`（保留 `companion`）。
- 重写 `updateMentionState`：取 `lastAt=draft.lastIndexOf('@')`，若无则关；截 `query=draft.slice(lastAt+1).trim().toLowerCase()`；在线候选 = `presence.filter(p=>p.userId!==selfId && !isCompanionId(p))` 先按 `enteredAt` 排序，再按 `query` 过滤（空 query 取前5，`displayName` 或 `role` 包含 query 则命中；大小写不敏感，支持拼音首字母可选不做），上限5；最终 `mentionCandidates=[companion?(companion→PresenceMember适配):[] , ...onlineCandidates]`（伙伴永远首位，若 `companion==null` 则无首位）；`mentionOpen = mentionCandidates.length>0`。
- `insertMention` 重载：入参 `candidate: PresenceMember|CompanionProfileWrapper`，拼 `@${candidate.displayName} `，`setDraft`，聚焦 `requestAnimationFrame` 置光标；若 `candidate` 来自在线真人，则 `onWhisperSelect(candidate)` 并关闭浮层（若为伙伴则保持现有 `onMentionCompanion` 行为）。
- 渲染：`.mention-item` 展示 `AvatarBadge 28px` + `mention-name` + `mention-role`（小字，角色为空则不渲染）；首位“伙伴”后可加微徽标（可选）；键盘导航沿用现 `mentionIndex` 取模；IME 防护不变。
- 保持 `keepFocus/pointerdown suppress` 与 `onMenuOpenChange` 联动。

## 3. App 状态与发送分支
- `src/App.tsx` 新增 `pendingWhisper: PresenceMember|null`（单次生效），`setPendingWhisper` 由 Composer 回调与头像/在线列表点击触发；`clearWhisper` 在发送后与 `draft` 不再含 `@name` 时触发。
- 重写 `handleSend` 优先级：
  1) 若 `pendingWhisper && draft.includes(@pendingWhisper.displayName)` 且 `pendingWhisper.userId !== selfId` → `room.send(text, blob, replyTo, {whisperTo:pendingWhisper})` 走云端，`setPendingWhisper(null)`，`setSentMessageSequence+1`，`recordMessageSent`（可选 `recordInteraction`）。
  2) else 若 `wantsPrivateCompanion`（原 `privateMode||containsCompanionMention||isEnterPrivateChatIntent`）→ `sendPrivateAndReply`。
  3) else 公共 `room.send`。
- `privateChatEntries` 保持伙伴本地；新增 `whisperEntries` 无需单独合并——云端返回的 whisper 已在 `room.entries` 中，只需在 `mergedEntries` 中对其打 `isWhisper` 标记以区分样式（在 `chatSync` 映射时已打）。
- 传递 `presence={displayPresence.filter(notCompanion)}` 与 `selfId` 给 `Composer`；`MessageList` 的 `isWhisperId=(id)=>room.entries.find(e=>e.id===id)?.whisperTo!=null` 或直接用 `entry.isWhisper`。

## 6. 边界与兼容
- 无在线真人时弹窗仅伙伴1条；有在线时最多6条（1+5）。
- 过滤规则同时匹配 `displayName` 与 `role`，为空回退显示前5在线。
- 发送前校验 `pendingWhisper` 仍在线（`presence.some(p=>p.userId===pendingWhisper.userId)`），离线仍允许发送（对方上线后通过分页拉取可见，RLS 保证可见性，不依赖 presence）。
- 图片私聊：`room.send('', blob, replyTo, {whisperTo})` 同路径已支持 `image_url`。
- 编辑/删除：`chatRemote.deleteMessage/updateMessage` 保持作者可删改；whisper 接收方不可删他人消息（RLS delete 仅作者）。
- 200行文件约束：`Composer.tsx` 已570行，拆 `src/components/Composer/MentionPopover.tsx` 与 `useMentionFilter.ts`；`App.tsx` 抽 `src/lib/whisperTarget.ts` 管理 `pendingWhisper` 单次生命周期。
