### Context
用户希望在与本地私聊助手的自然语言对话中（任意语言：中/英/日等），通过一句话如“来一盘五子棋”“play xiangqi”让助手自动识别意图，发出 one-hour 内置的游戏卡片（五子棋/中国象棋/国际象棋）并以助手身份自动入房，形成可直接落子的对局。当前游戏仅能通过 Composer 的 `+` → Games 手动触发（`App.handleStartGame` → `__GAME__` 标记），助手私聊为本地 IDB 且无意图解析，需打通 LLM 意图识别→公聊发卡→Realtime 入房的链路。

### Implementation Plan

**1. 扩展 `companionContext` 的 system prompt（可复用多语种能力）**
- 文件：`src/lib/companionContext.ts` `buildCompanionSystemPrompt`
- 在 10 语种分支中追加：若用户明确表达想玩某游戏（关键词不限语言），模型需在回复之外推断 `gameId`，并在后续结构化返回中使用。保持现有温暖伴侣语调与 1-4 句限制。

**2. 改造 `companion-chat` Edge Function 为结构化返回（复用 `game-ai-move` tutor 模式）**
- 文件：`supabase/functions/companion-chat/index.ts`
- 将 Baseten 调用改为 `response_format: {type:"json_object"}`，system prompt 要求严格 JSON：`{"reply": string, "game": "gomoku"|"xiangqi"|"chess"|null, "confidence": 0..1}`
- 校验：`game` 仅允许 `registry.getGameList()` 中的 `id`，否则置 `null`；保留现有 Tavily 搜索注入与 hardened 防泄露规则
- 返回体扩展为 `{reply, game, model, provider}`，保持向后兼容（无 `game` 时旧前端仍取 `reply`）
- 配置：保持 `max_completion_tokens:20000` 与现有 `supabase/config.toml` `verify_jwt=false`

**3. 前端请求层适配**
- 文件：`src/lib/companionChat.ts`
- `requestCompanionReply`/`requestCompanionGreeting` 改为解析 `{reply, game}`，增加类型 `CompanionReply {reply:string, game: GameId|null}`，保留 `fallbackReply` 时 `game=null`
- `toHistory` 不变

**4. App 层自动发卡与入房**
- 文件：`src/App.tsx`
- 新增 `handleCompanionGame(gameId)`：复用 `handleStartGame` 生成 `instanceId` 并 `room.send` 公聊卡片；成功后调用新增 `autoJoinCompanion(instanceId, gameId)` 
- `autoJoinCompanion` 实现：通过 `getSupabaseClient` 直接 `upsert` 对应 `gomoku_states|chess_states|xiangqi_states` 的 `players` 数组（参考 `cloudState.ts` 的 `save*State` 守卫与 `isGameHostAuthority` 逻辑），或通过本地 `Broadcast` 模拟 `join` 事件（需验证 Realtime 是否允许非 host 写入；优先采用 host 直写 state 方式，因新卡片的 host 即当前用户，前端即 host 权威可写）
- 在 `sendPrivateAndReply` 中：收到 `result.game` 非空且 `confidence>0.6` 时，先以私聊形式展示 `result.reply`，随后触发 `handleCompanionGame`，并追加一条系统提示私聊 “已为你创建xx对局，助手已加入”
- 状态：`privateChatEntries`/`mergedEntries`/`displayPresence` 维持现有合并与 1h 截断逻辑，无需改动

**5. Composer 与 @ 链路保持**
- 文件：`src/components/Composer.tsx`、`src/lib/mention.ts`
- 维持现有 `@` 浮窗与 `containsCompanionMention` 触发；游戏意图仅在私聊路径生效，不影响公聊

**6. i18n**
- 文件：`src/lib/i18n.ts` / `translations.ts` 无需新增，仅在系统提示中使用 `t(game.name, game.nameEn)` 已有键
